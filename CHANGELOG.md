# Changelog

All notable changes to The Chronicle Binder are documented here.

## 0.1.0 - 2026-11-15

### Added

- Desktop and command-line conversion of public Halo Waypoint Chronicles to EPUB 3.
- Curated Chronicle catalog, custom URL entry, folder-based output, and sequential bulk archiving.
- Waypoint-inspired and classic reading styles with artwork-based portrait covers.
- Publication, writer, publisher, plot, series, relationship, rights, and ebook-producer metadata.
- EPUB 2 navigation fallback, semantic landmarks, and EPUB Accessibility discovery metadata.
- Cancellation, overwrite protection, bounded downloads, and recoverable artwork failures.
- HTTPS-only host and redirect validation, raster image allowlisting, aggregate artwork limits, and hardened Pillow processing.
- Public-release documentation, fan-project notices, contributor guidance, and a private GitHub security-reporting policy.
